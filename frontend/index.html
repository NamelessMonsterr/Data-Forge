How DataForge works

DataForge helps you find, inspect, and package datasets. The web app drives the real ingestion path — parsing, schema inference, statistics, checksums, and ZIP packaging — plus offline semantic catalog search. The multi-agent planner is exposed at /workflow/start as a deterministic reference workflow for reviewing the planner, graph validation, and protocol layers. LLM calls run in deterministic offline mode by default; live NVIDIA NIM is opt-in via environment configuration.
