How DataForge works

DataForge separates discovery, upload processing, and catalog review into distinct workflows. The upload path performs parsing, schema inference, statistics, checksums, and ZIP packaging. Search uses the indexed catalog and optional live public providers. LLM calls stay deterministic offline by default and can be upgraded to NVIDIA NIM through environment configuration.
